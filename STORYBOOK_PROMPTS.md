# 📖 ReadSmart — DepEd Grade 3 Storybook Image Prompt Book

This document contains **ready-to-copy prompts** for Gemini, Imagen, Midjourney, or DALL-E to generate storybook visual illustrations for all 15 DepEd Grade 3 Reading Levels.

---

## 🎨 Global Art Style Instructions (Locked for Consistency)
* **Art Style**: Clean 2D children's storybook vector illustration, dark smooth line-art, whimsical elementary reader aesthetic.
* **Palette**: Warm cozy pastel tones (soft amber, warm peach, sky blue, sage green, cream).
* **Expressions**: Cheerful, expressive, friendly, kid-friendly (simple eyes, blush cheeks, welcoming smiles).
* **Aspect Ratio**: `4:3` (Storybook Landscape Frame).
* **Strict Negative Constraint**: `No text, no letters, no words, no speech bubbles, no watermarks, no frames`.
